# Generative AI and NLP Projects

## Overview

This repository contains a collection of Natural Language Processing (NLP) and Generative AI projects implemented using Python. The notebooks cover fundamental NLP concepts, text preprocessing techniques, information extraction, sentiment analysis, text classification, and text summarization.

The goal of these projects is to build a strong foundation in NLP workflows and machine learning techniques used in Generative AI applications.
